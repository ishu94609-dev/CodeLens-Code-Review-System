CodeLens is a code review system that helps identify code quality issues and provides useful guidance for improving source code.

Open the Analyze Code page, select your programming language, provide your code or upload a file, and start the analysis.

CodeLens displays detected issues, their severity, affected lines, explanations and code quality information.

Your previous analysis information can be accessed through the Results and History sections of CodeLens.

Code Analysis
